# Net Recovery Engine Demo

This is a Vite/React version of the Net Recovery Engine demo UI.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload these project files.
3. Go to Vercel.
4. Click **Add New > Project**.
5. Import the GitHub repository.
6. Click **Deploy**.

Vercel should detect this as a Vite app automatically.
